# Мониторы, сцены и визуализаторы

## Мониторная модель
`monitor_id` (стабильная Windows идентичность), `name`, `bounds`, `refresh_hz`, `connected`, `scene_mode`, `window_mode`, `position`, `size`, `always_on_top`, `info_visible`, `fps_cap`, `quality`, `visualizer_preset`, `preset_policy`, `intensity`, `reactivity`.

## Сцены
- `VIDEO`: собственный YouTube IFrame, синхронизированный с общим треком; muted кроме единственного audio authority.
- `VISUALIZER`: свой рендер, общий аудиоанализ; preset fixed/random (без немедленного повтора).
- `OFF`: сцена не создаёт окно и не рендерится.
- Если видео отсутствует, `VIDEO` временно отображает визуализатор, затем возвращается к видео.
- Отключённый дисплей: не переносить его окно на другой; восстановить на том же дисплее после подключения. Новый дисплей — ручная настройка.

## Визуализаторы
1. **Ambient:** обложка альбома, пульсирующий свет и мягкое свечение.
2. **Spectrum:** полосы FFT с адаптацией к громкости/частотам.
3. **Liquid:** плавные градиентные формы и движение от ритма.
4. **Particles:** частицы с реакцией на бас/транзиенты.
- Визуализаторы должны работать без подмены реального анализа вымышленным BPM.
- Обложка допускается только в визуализаторе; поверх клипа в info panel — только title + artist.

## Производительность
- WebGL hardware acceleration ON, без переключателя.
- Canvas2D fallback при реальной недоступности/ошибке WebGL; не переключать автоматически из-за игры/нагрузки.
- FPS options: 30,60,90,120,144,165,180,240; отфильтровать по заявленной частоте монитора; default = refresh_hz (если точного пункта нет, ближайший допустимый не выше refresh_hz — предложение).
- rAF/VSync; лимит FPS — максимум, не гарантия. `quality`: low/medium/high/ultra, независимый от FPS.
- Скрытые окна не должны активно рендерить. При этом звук не должен зависеть от видимости конкретного окна.
- Никакого auto game detection, auto GPU throttling, auto FPS lowering.

## Окна
- Borderless fullscreen на дисплее, Alt+Tab; F11 переключает, Esc выходит.
- Windowed/maximized/fullscreen, размер/позиция/монитор сохраняются; always-on-top отдельно, default OFF.
- Закрытие конкретного окна → hide; tray Open → восстановить все ранее скрытые, кроме `OFF`.
- Если Windows считает выключенный телевизор подключённым — не менять состояние.

## Инфопанель и управление
- Title + artist постоянно видимы, default нижний левый угол, выбор из 4 углов, общие настройки размера/opacity/position, per-monitor visibility.
- Курсор/контролы видимы только на мониторе с мышью; через 3 с неактивности скрываются; hover/drag/menu удерживает.
- UI overlay не должен блокировать YouTube player controls и seek там, где используется собственная шкала.

## Тестовая матрица
- 1 монитор, 2 монитора, 3 монитора; разные DPI, 60/120/144/180 Hz.
- Монитор HDMI отключился и вернулся, идентичность сохранена.
- TV power-off, Windows считает дисплей подключённым.
- Полноэкранная игра поверх одного окна, остальные работают.
- Один/несколько видео-плееров + визуализаторы; нет двойного звука.
- WebGL context lost → Canvas2D; возвращение по решению реализации, без бесконечного фликера.

## Миниплеер на одном дисплее

REQ-050/051: миниплеер не требует второго монитора и не создаёт дополнительную музыкальную сессию. Режим поверх окон включается вручную. Компактный размер окна не должен автоматически менять настройки FPS/качества сцены. Оконные адаптеры и ограничения topmost проверяются на Windows, macOS и Linux отдельно.
