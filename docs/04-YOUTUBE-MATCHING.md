# Поиск и выбор YouTube-видео

## Входные данные
`track_key`, исполнитель(и), заголовок, альбом, версия/explicit/live/remix markers, длительность Яндекс-трека (только сигнал для ранжирования), ранее выбранные видео.

## Pipeline
1. Проверить ручные избранные video IDs для `track_key`.
2. Если >=2 избранных — случайно выбрать, исключив непосредственно предыдущее при возможности; проверить доступность/embeddability.
3. Если избранное не работает — другое избранное; затем автоматический поиск.
4. Поиск кандидатов (предлагается `ytmusicapi`, альтернативы только после проверки ограничений). Нормализовать названия, артистов, спецсимволы, featuring, транслитерацию.
5. Фильтровать/ранжировать; проверять, можно ли воспроизвести в YouTube IFrame; кешировать результат с TTL.
6. Выбрать лучший релевантный кандидат. При ошибке перейти к следующему, затем к аудио fallback, если доступно.

## Сигналы ранжирования
**Сильные плюсы:** точное совпадение исполнителя/названия; официальный канал; `Official Music Video`, `Official Video`, `Official Lyric Video`, `Official Visualizer`; качественное live оригинального исполнителя.
**Минусы/исключения:** cover, karaoke, reaction, tutorial, чужой remix, фанатская нарезка, nightcore/slowed, unrelated artist; явная неподходящая версия.
**Нюансы:** live с другой длительностью допустим; duration mismatch сам по себе не дисквалифицирует. Качество/разрешение — слабый сигнал после релевантности; не обещать фактический 1080p.

## Override UI
- Поиск YouTube-видео для конкретной композиции, предпросмотр метаданных, вставка URL, добавление/удаление нескольких избранных, сброс к автоподбору.
- Принимать только валидные YouTube watch/short/youtu.be URL, извлекать **video ID**, не хранить произвольные URL как исполняемый контент.
- В настройках композиции показывать список избранных и отметку о недоступности.
- Пульт телефона предоставляет те же действия с авторизацией.

## Кэш
`video_candidate(track_key, video_id, source, score, checked_at, embeddable_status, reason)`; `track_video_favorite(track_key, video_id, added_at, last_used_at)`.
- Устаревшие/удалённые ролики не удалять из пользовательских избранных без подтверждения, помечать unavailable и пробовать другие.
- Не скачивать ролики, не извлекать медиапотоки и не обходить embed restrictions.

## Тесты
- Оригинальный клип выигрывает у кавера с большим числом просмотров.
- Live оригинального исполнителя разрешён, если студийного клипа нет.
- Разная длительность не обрезает ролик.
- Два избранных не повторяются подряд при повторе одной песни.
- Битая ссылка не ломает очередь.
- YouTube API вернул candidate, но IFrame запретил embed → следующий кандидат.

## Уточнение подбора по решению пользователя, 2026-11-03

Имя загрузившего канала не является условием совпадения с исполнителем. Среди найденных подходящих кандидатов приоритет отдаётся просмотрам; релевантность и исключение каверов/реакций/минусовок применяются до популярности. Метаданные настоящей artist credit в OMV могут подтверждать исполнителя, но пользовательский byline не используется как identity gate. Когда название песни совпало, а исполнитель из текста/канонических метаданных неизвестен, показываем кандидатов для выбора, не притворяясь уверенным подбором.
