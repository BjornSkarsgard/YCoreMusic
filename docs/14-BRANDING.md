## Внутренние идентификаторы

По решению пользователя 2026-11-07 весь исходный код, документация и имена
ресурсов используют только актуальное имя. Идентификатор приложения —
`io.ycore.desktop`, сервис credentials — `io.ycore.desktop/yandex-oauth`,
файл базы — `ycore.sqlite`, ключи localStorage — `ycore.*`,
тестовые переменные — `YCORE_*`, аргумент автозапуска — `--ycore-autostart`.

Смена идентификатора создаёт отдельный профиль ОС и отдельную запись аккаунта.
Автоматического обращения к прежним ключам нет. Старые данные пользователя
не удаляются. До следующего публичного выпуска нужно отдельно решить и проверить
перенос входа, истории, настроек WebView и привязки пульта из установленных версий.
Уже опубликованные пакеты и история Git этой правкой не изменяются.
Локальную папку проекта пользователь переименовывает самостоятельно.
