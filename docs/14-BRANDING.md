Полное название используется в заголовках окон, установщике, трее, системном медиаплеере и настройках. В компактном логотипе шапки — YCore. Слоган приведён без изменения пунктуации.

## Совместимость сохранённых данных

Название продукта не меняет `io.encore.desktop`, сервис credentials `io.encore.desktop/yandex-oauth`, файл `encore.sqlite`, localStorage-ключи `encore.*`, внутренние IPC-события и тестовые переменные `ENCORE_*`. Это идентификаторы совместимости: их сохранение позволяет открыть прежний аккаунт, историю и настройки без копирования или чтения токена. Автозапуск использует новое имя и `--ycore-autostart`, прежний `--encore-autostart` распознаётся. На машине пользователя старая запись автозапуска отсутствовала; переименование не включает автозапуск и не меняет настройки ОС.

Исторические записи документации и ADR сохраняют прежнее имя; актуальные команды сборки и пути в README относятся к YCore Music. Переименование не означает завершение экспериментального единственного player host: этот рефакторинг сохраняется отдельно до своей приёмки.
