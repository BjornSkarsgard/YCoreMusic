## Проверенный прототип

`audio-probe` — необязательная сборочная возможность. Команды доступны только
главному окну изолированной debug-сессии. Источник — дерево процессов браузера
WebView2 единственного `player-host`, определяемое самим приложением. Нет
захвата микрофона, общего системного микса, записи PCM или смены аудиовыхода.

Windows process-loopback отдаёт Float32, stereo, 44100 Hz. Проверены три
двухсекундных прогона настоящего YouTube: каждый получил 87759 кадров.

| Условие | Peak | RMS |
|---|---:|---:|
| Громкость YouTube 0 | 0 | 0 |
| Громкость YouTube 10%, собственная render-сессия muted | 0 | 0 |
| Громкость YouTube 1%, собственная сессия unmuted | 0.0105993 | 0.000476572 |

После тестов громкость источника возвращалась в 0 до восстановления mute.
Изменение mute относится только к собственному источнику и остаётся тестовой
функцией; продукту не требуется менять системную громкость.

Эти результаты доказывают сигнал при слышимом воспроизведении, но **не** анализ
до регулировки громкости: реактивность при громкости 0 не решена. Системный
микс или вымышленный ритм не считаются допустимой заменой.

## Продуктовая интеграция

Добавлен ограниченный FFT-анализ: окно Hann на 2048 кадров, 48 логарифмических
полос 30–16000 Hz. Общий process-loopback/FFT обслуживает видимые сцены;
только амплитуды передаются через IPC с ограничением около 30 обновлений/с.
При отсутствии видимых подписчиков capture закрывается. Lease на подписку
истекает через 3 секунды, нативная видимость проверяется независимо от UI.

Spectrum рисуется WebGL, при ошибке/потере контекста используется Canvas2D.
GPU-отрисовка использует собственный rAF и выбранный лимит каждого окна;
скрытая/свёрнутая сцена не рисуется. Настройки VIDEO/VISUALIZER, FPS, quality
сохраняются отдельно в scene-layouts.json с совместимыми defaults старых схем.
Громкость и выход звука продуктовая интеграция не меняет. `audio-analysis`
включён по умолчанию, реализация захвата доступна только Windows.

Сырые аудиоданные не записывались; сохранён только снимок своего окна
