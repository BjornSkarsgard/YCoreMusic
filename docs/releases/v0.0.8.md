# YCore Music 0.0.8

- Тексты текущей песни в мобильном пульте.
- Меню действий с треком в поиске, очереди, истории, чарте и медиатеке.
- Волна по треку, исполнителю и плейлисту, похожие треки и исполнители.
- Новинки и персональные подборки Яндекс Музыки.
- Создание и редактирование плейлистов, сохранённые альбомы.
- Если Яндекс возвращает только бэк-вокал, поиск текста продолжается у других поставщиков.
