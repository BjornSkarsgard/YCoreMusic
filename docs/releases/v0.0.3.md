# YCore Music 0.0.3

## Интерфейс

- Выпадающие списки используют тёмную тему YCore Music. При раскрытии голубая рамка убрана. Клавиатурный фокус по Tab виден.
- В «Других видео» выровнены превью. Исправлены отступы в настройках и списках треков.
- «Обзор» переименован в «Чарт». Повторный заголовок внутри панели убран.
- У логотипа-заглушки убран чёрный прямоугольник поверх видео.

## Обновления и поддержка

- Приложение проверяет новую версию при запуске и показывает предложение, когда окно активно и музыка на паузе. «Позже» откладывает предложение на сутки.
- После скачивания и проверки подписи кнопка «Перезапустить и обновить» устанавливает обновление Windows без мастера. При обновлении DEB система может запросить права.
- Переход с 0.0.2 использует установщик в режиме, заданном в 0.0.2. Тихий режим действует при следующем обновлении с 0.0.3.
- Кнопка «Поддержать» доступна в настройках. Напоминание об отзыве или поддержке можно отключить.

Пакеты для Windows x64 и Linux x86_64 (DEB и AppImage). Раскрытые списки полностью оформлены в Windows WebView2. Движки без поддержки настраиваемого меню используют системное отображение.
