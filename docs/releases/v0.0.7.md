# YCore Music 0.0.7

- Тексты песен рядом с клипом и в отдельном окне с настраиваемым размером шрифта.
- Поиск через Яндекс Музыку, LRCLIB, lyrics.ovh, LrcAPI, Pesni.net и KuGou. Если у ремикса нет текста, можно увидеть слова подтверждённого оригинала с отдельной пометкой.
- Перевод текста на русский через Google Переводчик по кнопке.
- Точнее подбираются видео для каверов и ремиксов. Табулатуры отфильтровываются при поиске текста.

Сборки macOS для Intel и Apple Silicon экспериментальные.
