# YCore Music 0.0.5

- Улучшен подбор клипов: перед пропуском песни приложение повторно проверяет неудачный предварительный поиск.
- Неоднозначные результаты больше не мешают получить свежую выдачу. Если подходящий клип не найден повторно, воспроизведение продолжается со следующего трека.
- Проверено воспроизведение «ПАКЕТ» — SQWOZ BAB.

После обновления потребуется повторный вход в Яндекс и подключение телефонного пульта. Локальные история и настройки предыдущей версии не переносятся.

Windows и Linux; macOS Intel и Apple Silicon — экспериментальные сборки без нотариализации и проверки на физическом Mac.
