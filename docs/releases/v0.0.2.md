# YCore Music 0.0.2

Исправления непрерывного воспроизведения для Windows x64 и Linux x86_64.

- Исправлена остановка подбора у записей без числа просмотров или длительности. Проверены Absence — Xalv и What I Need — Catch-22 NZ через поиск в приложении.
- Недоступные и зависшие клипы автоматически сменяются следующим подходящим вариантом или треком в волне, плейлистах, альбомах, поиске и истории.
- Плеер проверяет движение времени видео, даже если YouTube продолжает сообщать «Воспроизведение».
- Фоновый поиск альтернатив больше не блокирует основной подбор. Ожидание поиска и дозагрузки очереди ограничено по времени.
- Явная пауза сохраняется; при отсутствии сети приложение ждёт подключения. Конечные списки сохраняют правила завершения и повтора.

Проверки: 151 UI-тест, 16 модульных тестов; нативное воспроизведение обоих проблемных треков через поиск. Windows-установщик без Authenticode; пакеты обновлений подписаны ключом приложения.

Linux: Ubuntu 24.04 x86_64; DEB и AppImage. Для сохранения входа требуется разблокированный Secret Service, например GNOME Keyring. Полная поддержка других дистрибутивов и нативного GTK/Wayland не заявляется.
