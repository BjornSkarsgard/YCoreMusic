# YCore Music 0.0.6

- Исправлено появление отдельного окна с клипом в Linux. В X11 с композитором служебное окно скрывается. Если подходящий композитор недоступен, клип показывается прямо в приложении.
- При переключении треков у конца плейлиста прокрутка сохраняет позицию во время подбора клипа.

Для зеркал клипа и визуализаторов в Linux требуется X11 с работающим композитором. Оконное поведение проверено в обоих режимах X11. Сборки macOS для Intel и Apple Silicon остаются экспериментальными.
