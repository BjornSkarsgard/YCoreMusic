## Как принимать решения
- Изменения согласованного UX — спрашивать пользователя.
- Внутренние параметры/пороговые значения — можно выбирать и фиксировать ADR, если не нарушают требования.
- При блокере внешнего API — сначала техническое доказательство, затем варианты с явным указанием, какие REQ не выполняются.
